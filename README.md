## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (for Expo-based projects)
- [Android Studio](https://developer.android.com/studio) (for Android emulator)

### Installation

```bash
# Clone the repository
git clone https://github.com/yigituygun8/typescript-reactnative.git

# Navigate to a project directory
cd typescript-reactnative/<project-folder>

# Install dependencies
npm install

# Start the project (for React Native / Expo projects)
npx expo start
```
